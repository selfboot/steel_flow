## 1. 产品概述 / Product overview

SteelFlow 是面向金属加工、五金贸易、钢构安装、采购报价和专业 DIY 用户的随身材料计算与报价工具。用户选择型材、输入尺寸和数量后，App 给出可核对的截面积、单件重量、总重量、材料成本、损耗与报价，并可把多个条目组成项目，导出中英文 PDF 或 CSV。

SteelFlow is a pocket material calculator and quoting tool for fabricators, metal suppliers, contractors, estimators, buyers, and serious makers. Users select a stock profile, enter dimensions and quantity, verify the resulting area and weight, add cost and margin, then export a bilingual-ready PDF quote or CSV cut list.

### 核心承诺 / Core promise

> 从尺寸到重量、成本和报价单，一次完成，结果可核对。
> From dimensions to weight, cost, and a send-ready quote—with calculations you can verify.

## 2. 背景与机会 / Why now

中国区现有钢材计算工具证明用户愿意直接付费，但低星评论长期集中在材料规格缺失、计算或行情错误、换机后权益丢失、付费后不可用，以及只给一个数字却不能生成项目交付物。海外市场也存在大量单用途 weight calculator，但跨单位、跨币种、报价和可分享交付往往分散在计算器、表格和 PDF 模板之间。

机会不是再做一个公式列表，而是完成这条价值链：

`型材与尺寸 -> 可解释的确定性计算 -> 项目成本与报价 -> 可发送 PDF/CSV`

## 3. 目标用户 / Target users

### P1：小型金属加工店老板 / Small fabrication shop owner

- 需要在车间、客户现场或聊天中快速报价。
- 目前使用纸张、手机计算器、Excel 和微信反复抄写。
- 关心重量、损耗、材料成本、加工费、利润和报价速度。

### P2：报价员或采购 / Estimator or buyer

- 同时处理多个规格、单位、供应商价格和币种。
- 需要留下计算依据，并把结果发送给同事或客户。
- 关心项目模板、可复核结果、CSV/PDF 和历史价格。

### P3：现场安装与工程人员 / Field contractor

- 需要在现场按长度、数量和型材估算运输重量及材料金额。
- 网络可能不稳定。
- 关心离线、快速输入、大字体和不丢数据。

### P4：专业 Maker / Serious maker

- 需要为焊接、车库项目或小批量制作估算材料。
- 不需要 ERP，但愿意为无广告、清晰和可靠的工具买断。

## 4. 用户任务 / Jobs to be done

1. 当我拿到一组尺寸时，我想快速得到重量和成本，避免手工查表及换算错误。
2. 当客户询价时，我想把若干材料组成一个项目，加入损耗、税费、加工费和利润，生成可发送报价。
3. 当我需要复核结果时，我想看到公式、截面图、单位、密度来源和舍入规则，而不是只看到一个黑盒数字。
4. 当我在不同国家或与海外客户合作时，我想使用正确的单位、币种、数字格式、纸张尺寸和语言。
5. 当我换机或归档项目时，我想恢复购买并导出自己的数据，不依赖账号。

## 5. 目标与非目标 / Goals and non-goals

### 5.1 v1 目标

- 30 秒内完成一个常用型材的重量与成本计算。
- 将多个计算条目组成项目并生成专业 PDF/CSV。
- 对每个结果提供可核对的几何参数、密度和公式说明。
- 简体中文和英语达到功能、布局和导出文件同等质量。
- 支持公制与美制单位、任意 ISO 4217 币种和本地数字格式。
- 完全离线完成核心工作，无账号、广告和强制联网。

### 5.2 v1 非目标

- 实时钢材或大宗商品行情。
- 供应商交易、采购商城或支付。
- ERP、库存会计、电子发票或各国税务申报。
- CNC/CAM、G-code、二维板材套料或复杂三维建模。
- 多人实时协作、云同步或 Web 后台。
- 把标准组织受版权保护的完整型材表未经许可内置。
- 对结构安全、载荷、强度或工程适用性作判断。

## 6. MVP 功能范围 / MVP scope

### 6.1 快速计算 / Quick calculation

首发型材：

1. 钢板/扁钢 / Plate & flat bar
2. 圆钢 / Round bar
3. 方钢 / Square bar
4. 六角钢 / Hex bar
5. 八角钢 / Octagonal bar
6. 圆管 / Round tube or pipe by OD and wall thickness
7. 方管 / Square tube
8. 矩形管 / Rectangular tube
9. 角钢 / Equal or custom angle
10. 槽钢 / Channel with user-entered geometry
11. 工字/H 型截面 / I/H section with user-entered geometry
12. T 型钢 / T section with user-entered geometry
13. 自定义截面积 / Custom cross-sectional area

每个条目支持：

- 尺寸、长度、数量、材料、密度和单位。
- 单件重量、总重量、截面积和体积。
- 单价按重量、长度或件计。
- 损耗率、税率、加工费、其他费用和利润率。
- 项目内备注、内部编号和客户可见描述。
- 输入范围校验及壁厚/尺寸几何约束。

### 6.2 材料目录 / Material catalog

首发内置常用、非品牌化密度预设：

- Carbon steel / 碳钢
- Stainless steel 304 / 304 不锈钢
- Stainless steel 316 / 316 不锈钢
- Aluminum / 铝
- Brass / 黄铜
- Copper / 铜
- Cast iron / 铸铁

要求：

- 所有密度可查看、复制和覆盖。
- 用户可创建自定义材料、名称、密度和备注。
- 内置数据必须带版本、来源说明和“典型值”提示；不把密度预设包装为材料认证。

### 6.3 项目 / Projects

- 创建、复制、归档和删除项目。
- 项目字段：名称、客户、项目编号、日期、币种、默认单位、报价语言、税率、有效期、条款和备注。
- 从快速计算保存到项目。
- 条目排序、复制、批量修改损耗或价格。
- 项目汇总：净重、含损耗重量、材料成本、加工费、税前金额、税额、总价、预计利润。

### 6.4 报价与导出 / Quote and export

- 中英文 PDF 报价单。
- A4 与 US Letter。
- 报价编号、公司名称、Logo、联系信息、客户、有效期和条款。
- 可控制客户是否看到单位重量、材料成本、利润和内部备注。
- CSV 导出计算条目和项目汇总。
- iOS 分享、AirPrint、保存到 Files。
- 导出前预览，显示分页与字段可见性。

### 6.5 设置与本地化 / Settings and localization

- 跟随系统或手动选择中文/English。
- 默认单位：公制 / US customary；每个字段可临时切换单位。
- 默认币种、税率、纸张、数字精度和舍入方式。
- 公司资料与报价模板。
- 恢复购买、导出全部数据、导入备份、删除全部数据。

## 7. 功能需求与验收标准 / Functional requirements

### FR-001 型材选择

用户可以通过图形和中英文名称选择型材。最近使用的型材优先显示，但不改变完整目录顺序。

**验收：** 新用户最多两次点击进入任一首发型材；VoiceOver 能读出名称和截面描述。

### FR-002 单位输入

每个尺寸字段显示单位，并可在兼容单位间切换。转换后实际物理值不变。

**验收：** 25.4 mm 切换后显示 1 in；再次切回不产生可见累计误差。

### FR-003 确定性计算

修改任何有效输入后立即重新计算。结果包含单位重量、总重量、面积和体积。

**验收：** 支持的公式与验证语料中的参考值在定义公差内一致；无效几何不输出结果。

### FR-004 计算依据

用户可以展开“计算详情 / Calculation details”查看输入快照、公式类型、密度、内部单位和舍入。

**验收：** 每个结果都可追溯到明确输入和材料密度，不出现不可解释的 AI 数值。

### FR-005 价格与利润

支持按 kg、lb、m、ft 或 piece 输入价格，并加入损耗、加工费、税和利润。

**验收：** 金额使用 Decimal 计算；显示符合项目币种的小数位和本地格式。

### FR-006 项目管理

用户可保存、复制、重排和归档项目及条目。

**验收：** 强退并重启后，最近一次已提交的编辑仍存在；删除提供撤销机会。

### FR-007 PDF 报价

用户可设置客户可见字段并导出 A4 或 Letter PDF。

**验收：** 中文、英文、长客户名称、100 个条目均不截断关键金额；分页表头重复。

### FR-008 CSV

用户可导出 UTF-8 CSV，包含机器可读数字和单位字段。

**验收：** Excel、Numbers 和 Google Sheets 导入后，中文与英文均无乱码。

### FR-009 本地化

所有界面、错误、PDF 标题和系统分享文件名支持简体中文与英语。

**验收：** 切换语言后无需重建数据；没有硬编码英文；复数和数字格式符合 locale。

### FR-010 数据可移植性

用户可以导出包含项目、材料、设置和模板的版本化备份并重新导入。

**验收：** 导入前预览对象数量和版本；冲突时允许复制导入或取消，不静默覆盖。

### FR-011 购买

免费版可以完成真实计算；Pro 解锁无限项目、自定义报价和完整导出。

**验收：** 购买可恢复；离线时已缓存 entitlement 仍可使用；不会要求创建账号。

## 8. 免费版与 Pro / Packaging

### 免费版

- 全部基础型材和材料预设。
- 无限快速计算。
- 最多 2 个活跃项目、每项目 10 个条目。
- 带 SteelFlow 标识的基础 PDF。
- CSV 预览但不导出。

### Pro 一次买断

- 无限项目与条目。
- 自定义材料、公司资料、Logo 和报价条款。
- 完整 PDF/CSV 和版本化备份。
- 批量编辑、项目复制和高级型材。

### 首轮价格假设

- 中国大陆标准价：¥58；可选 30–45 天首发价 ¥38。
- 美国标准价：US$14.99；可选 30–45 天首发价 US$9.99。
- 其他市场使用 App Store 分区定价，不直接按汇率硬换算。

最终价格必须通过真实报价任务和价格选择测试验证。

## 9. 信息架构 / Information architecture

主导航使用四个 Tab：

1. **计算 / Calculate**：型材选择、最近计算、快速新建。
2. **项目 / Projects**：项目列表、项目详情、报价预览。
3. **材料 / Materials**：材料密度和自定义材料。
4. **设置 / Settings**：语言、单位、币种、报价资料、购买和数据。

关键流程：

`计算 -> 选择型材 -> 输入尺寸 -> 查看结果 -> 保存到项目 -> 调整价格/利润 -> 预览报价 -> 分享 PDF`

## 10. 国际化需求 / Internationalization requirements

- 首发 `zh-Hans` 与 `en`，架构允许后续加入德语、日语、西班牙语。
- UI 使用本地化 String Catalog，不用英文作为程序逻辑键。
- 存储统一使用 SI 基础单位，同时保留用户原始输入单位。
- 支持小数点和小数逗号输入；显示使用当前 locale。
- 币种按 ISO 4217，不假设所有币种有两位小数。
- PDF 支持 A4、US Letter；日期、地址、税名和数字格式可本地化。
- 中英文报价可独立于 App 界面语言选择，方便跨境客户。
- 型材别名支持地区差异，如 RHS/rectangular tube、SHS/square tube、H-beam/I-beam，但计算模型不依赖名称。

## 11. 非功能需求 / Non-functional requirements

- 冷启动目标：现代设备上 1 秒内进入可操作状态。
- 输入后计算反馈：50 ms 内完成普通条目计算。
- 500 个项目、每项目 200 个条目仍可流畅滚动与汇总。
- 100 条报价 PDF 在普通设备上 2 秒级生成，不阻塞主线程。
- 核心计算不联网；无网络时除购买和外部链接外功能完整。
- Dynamic Type、VoiceOver、键盘导航、足够对比度和 44pt 触控目标。
- 不收集计算、客户、项目或报价内容。

## 12. 风险与缓解 / Risks

| 风险 | 影响 | 缓解 |
|---|---|---|
| 公式或输入错误 | 报价错误、材料浪费 | 确定性引擎、参考语料、边界校验、计算详情、免责声明 |
| 标准表版权/许可 | 无法合法内置完整标准型材 | 首版用户输入几何；只用授权、公开或自建数据；记录来源与版本 |
| 国际单位混淆 | 10x/25.4x 级错误 | 每字段单位、内部 SI、输入快照、显式转换测试 |
| 价格只是一次性计算 | 付费价值低 | 项目、报价、历史、模板和可交付 PDF 形成闭环 |
| 功能扩张为 ERP/CAD | 延期、支持成本失控 | 坚守计算—报价—导出；后续能力单独验证 |
| 国内备案不确定性 | 中国区上架延误 | v1 纯离线、无账号/远程内容；尽早创建 App Store 记录并确认适用要求 |

## 13. 成功指标 / Success metrics

### 验证期

- 10 位目标用户中至少 7 位能无指导完成一个真实计算。
- 至少 5 位用真实项目生成并发送报价或下料 CSV。
- 至少 3 位在价格选择中接受目标区间，而不只留下邮箱。
- 参考语料中的核心公式零已知错误。

### 上线后

- 首次计算完成率 ≥ 70%。
- 完成计算的用户中，保存到项目比例 ≥ 25%。
- 创建项目的用户中，7 日内导出 PDF/CSV 比例 ≥ 30%。
- 退款原因中“结果不正确”必须逐案复现，任何确认错误均作为最高优先级处理。

这些是产品决策阈值，不是未经验证的市场预测。

## 14. 里程碑 / Milestones

1. **验证原型（1–2 周）**：5 种型材、计算详情、单项目报价样例。
2. **Alpha（3–5 周）**：完整计算引擎、项目、本地材料和双语基础 UI。
3. **Beta（2–3 周）**：PDF/CSV、备份、RevenueCat/StoreKit、iPad、无障碍与本地化 QA。
4. **Release candidate（1–2 周）**：100+ 参考案例、真实报价回归、隐私与商店材料。
