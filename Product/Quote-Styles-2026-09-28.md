# 报价 PDF 风格

## 设计与入口

参考 [Zoho 极简票据模板](https://www.zoho.com/invoice/invoice-templates/sample/zoho-invoice-minimalist-template.pdf) 的信息分区，以及 [PandaDoc 报价模板](https://www.pandadoc.com/price-quote-template/) 的公司、客户、明细和总额结构，使用 UIKit 矢量文字和色块重新实现适合材料报价的版式。未采用第三方模板图片，也没有将报价内容栅格化。

| 风格 | 版式 |
| --- | --- |
| 经典 | 保留原有紧凑布局，兼容现有项目和旧历史记录 |
| 清爽蓝 | 蓝色细线、浅色表头、双栏抬头和客户信息、右侧白底总额 |
| 商务墨绿 | 墨绿文字和细线、浅绿表头、白底明细与总额 |
| 极简黑白 | 黑白标题、细分隔线、白底明细与右侧总额 |

入口为“项目 → 报价预览 → 报价风格”，也可在项目设置中选择。选择页展示由真实 PDF 渲染器生成的示例缩略图，实际报价预览随选择立即更新。四种样式均可选择，不新增付费限制；已有公司资料、条款及 Pro 去品牌规则保持不变。

## 数据行为

- 按项目保存，项目复制与模板复用均保留风格。
- 备份携带可选风格字段；旧备份缺失字段时使用经典。
- 报价快照冻结风格，历史版本不会因项目风格改变而重排。旧快照缺失字段或遇到未来未知样式时回退经典。
- 更换预览风格后，需要保存新的历史版本。原版本保持不变。
- 项目设置中的风格是草稿，取消设置会放弃选择。
- 切换风格先完成 PDF 生成与项目持久化，再替换当前导出。失败时保留原预览和已保存版本状态。
- 八种语言的风格名称和说明均已本地化；A4、Letter、可选重量与单价列沿用原设置。

## 默认报价设置

设置页“报价设置”新增“默认报价样式”，纸张尺寸从“语言和地区”移入同一区域。默认样式可使用同一套真实缩略图选择器，说明文案明确仅影响新建项目。

项目列表的新建项目、计算器“创建并添加”都读取默认样式；纸张继续使用现有 `app.paper` 偏好。已有项目和模板的已存字段保留，历史报价不被全局默认值覆盖。预览的默认选择规则见下方修正。默认样式随备份导出，旧备份缺少该偏好时恢复为经典样式。

备份往返、旧格式兼容、非法样式拒绝与八语言文案检查共 17 项单元测试通过，记录在 `DefaultSettingsRegression.xcresult`。

`DefaultSettingsComplete.xcresult` 中的完整 UI 回归通过：设置默认墨绿与 Letter、已有项目仍为经典与 A4、两个新建入口均采用墨绿与 Letter、重启后默认值保留。已检查浅色与深色设置页截图；截图位于 `Build/QuoteStyles/DefaultSettingsFinalQA/`。

## 预览默认样式修正（构建 22 上传之后）

用户在设置页选择样式后，每次打开新的报价预览都使用该默认样式，包括已有项目。生成快照时显式传入样式，不为应用默认值而改写项目数据。预览内手动切换仍生效；同一次预览中的重试和购买 Pro 后重新生成会保留当前选择。关闭后重新打开预览则重新读取设置默认值。

历史报价继续使用保存时的快照，纸张尺寸继续读取项目本身设置。设置说明同步更新了八种语言，区分预览默认样式和仅用于新项目的纸张默认值。

本轮修复已随 1.3（23）上传苹果并处理成功，见 [发布记录](AppStore/Release-1.3-23-2026-09-28.md)。

验证：构建通过；12 项报价样式与本地化单元测试、预览默认值与版本保存 UI 测试通过（`PreviewDefaultsRegression.xcresult`）。完整默认设置 UI 测试首次因纸张选择器自动返回而失败，适配该行为后重跑通过（`PreviewDefaultsUI.xcresult`）：覆盖已有项目预览跟随默认墨绿、切换默认蓝色后再次预览、新建项目两个入口及重启持久化。无编译警告。

## 新增三套商务样式

新增正式商务（居中抬头与双细线）、现代重点（大标题与通栏总价）、清晰账式（紧凑网格表），共七种样式。默认设置、项目、历史快照、备份及模板均支持新增样式。设计参考、提示词与验证结果见 [商务样式记录](Design/BusinessQuoteStyles-20260928/README.md)。已随 1.3（24）上传苹果。

## 构建 24 后的 Review 修复

移除项目设置里不会影响新预览的样式入口。全局默认样式继续控制每次新预览；在预览内切换仅更新当前快照和导出文件，不再改写项目样式或修改时间，保存版本仍冻结当前选择。八语言说明同步明确此规则。

移除项目条款、公司默认条款输入及相关 Pro 解锁入口，Pro 权益、模板说明、公司 Logo 分区标题同步清理八语言的条款承诺。项目内部备注、Logo 和公司资料继续可编辑。历史条款、公司默认条款及项目样式的数据字段、备份与快照兼容逻辑保留；编辑项目或公司资料不再写入这些隐藏字段。
