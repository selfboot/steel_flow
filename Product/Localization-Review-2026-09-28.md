# 德语、西班牙语、法语支持与场景 review

范围：App 内本地化；保持版本 1.3 (21)。新增 `de`、`es`、`fr`，共支持 8 种语言。每种新增语言包含 568 条文案，覆盖计算、材料、价格库、项目、报价、备份和 Pro 提示。App Store 商店文案和截图不在本次变更内。

## 实现

- 系统语言匹配及 App 内手动切换均支持三种语言，新项目报价语言随默认语言选择。
- 系统模式保留地区设置；验证德国、奥地利、瑞士、西班牙、墨西哥、美国西语、法国、加拿大法语的语言匹配。数字区域格式另覆盖 `de_CH`、`es_MX`、`fr_CA`。
- 本地化报价标题、金额、日期、单位、声明；备份往返保留新语言。
- Pro 权益明确说明 PDF 移除 SteelFlow 标识，免费与 Pro 的 PDF 行为保持一致。

## Review 发现与修复

1. 法语计算页的材料选择值被原生 Picker 截成 `Acier a…rbone`。改用可换行的菜单标签，保留原有选择绑定及无障碍大字布局。
2. PDF 长表头会在单词中间拆开。优先在空格处换行，超长连续字符和中日韩文本继续按字符换行；表头高度按实际行数计算。
3. 西班牙语 PDF 数量缩写 `Cant.` 超出原固定窄列。数量列按本地化文本宽度设置。
4. 更新旧测试假设：法语不再属于不支持的语言；PDFKit 将金额中的不换行空格提取为普通空格时，测试仍验证数值及位置。

## 第二轮 review 修复与回归

第二轮检查补充发现并修复了两处问题：

- 已有项目明细的单价、加工费、其他费用，以及选取的历史价格，之前直接把存储用的点号小数交给当前语言解析。现在统一使用 `AppFormatters.decimalInput` 转换为本地化编辑文本，保存时仍使用规范化 Decimal 文本。
- PDF 在按空格拆行后，剩余长词仍可能超宽，导致绘制丢字符。现在重复检查余段宽度，必要时继续按字符拆分。

新增回归测试：

- `testPDFPreservesLongWordsAfterShortPrefixes`：A4、Letter × 4 种短前缀 × 3 种连续字符，共 24 个组合。逐字符比较导出内容，包含曾将 160 个 O 导出为 159 个 O 的场景。
- 德语、西班牙语、法语各 1 项 UI 测试：打开已有明细并反复保存；检查 `2,345` 单价、`1,25` 加工费和 `0,125` 其他费用；选择 `4,567` 历史价格后保存并再次打开验证。

最终验证：`Build/EuropeanLocalization/ReviewFixRegression.xcresult`，**102 项单元测试 + 3 项新增 UI 测试全部通过，0 失败**。`git diff --check` 通过。本轮未重新执行 Release 编译。
