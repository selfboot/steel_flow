# SteelFlow UI 与交互修复记录

基线：`main / 28f0904`。对应 [UI 评估 U01–U14](UI-Interaction-Audit-2026-09-08.md)。本轮改动在当前工作目录；后续按用户要求调整计价折叠方式，并以 1.1.0（10）发布。

## 已实现

| 编号 | 修复结果 |
| --- | --- |
| U01 | 区分“更改项目币种”和“按项目币种保存条目”；明确操作仅影响新条目；预览单价与费用前后值；换算/清空/保留各有明确保存按钮。 |
| U02 | 尺寸、几何关系、长度、数量、密度、损耗和金额校验；字段旁显示原因；计算页底部错误入口滚动并聚焦输入；数量保留非法值等待修正，不再静默截断；无效结果保留占位。 |
| U03 | 模板选择不会立即创建；先显示条目、材料、税率和利润设置、清价策略，再明确确认创建并打开项目；保存模板支持命名与反馈。 |
| U04 | 搜索无结果、无模板、归档为空与无项目分别显示；创建和筛选入口分开；清除筛选恢复列表并退出键盘；材料和客户有搜索空态。 |
| U05 | 批量修改默认全部关闭；勾选条目，显示规格和固定选择数；全选当前筛选累加集合；确认页逐项展示旧值→新值；支持撤销。 |
| U06 | 计算页固定保存与重量；项目页前置条目数、总重、总额，费用明细折叠；报价与批量撤销入口固定可见。最大辅助字号使用短保存标签，避免底栏挤压表单。 |
| U07 | 首页前置草稿与常用收藏，限制首屏条数并提供查看全部；卡片展示材料、尺寸、长度/数量、重量与星标；卡片正文使用主文本色。 |
| U08 | 材料前置，密度与 3D 按需展开；附加费用、来源和备注分组；费用折叠时仍显示金额；客户、公司和材料表单保留字段标签。 |
| U09 | 保存提供查看项目、撤销、同规格继续和新规格；收藏、恢复草稿、重新开始、模板与复制提供反馈；重新开始可恢复输入；键盘前后项导航保留焦点。 |
| U10 | 报价页先显示真实 PDF 与页数；主路径保存固定版本后打开系统分享；保留明确的次级导出与按用途命名的 CSV；导出错误可重试；取消分享不记录为发送成功。 |
| U11 | 报价历史详情显示版本号和保存身份；比较包含新增、修改及删除项，并展示前后规格、数量和金额；跨币种不算虚假差额；复制修订打开新项目。 |
| U12 | 材料/供应商价格分开搜索与创建；置顶状态可见、菜单随状态切换；材料创建与复制接续解锁前操作。 |
| U13 | 结果与总额使用主色和等宽数字；持久字段标签；明确“项目设置”“管理条目”“新建/编辑客户”；卡片有按压反馈；主要输入区至少 44 pt 高。 |
| U14 | iPad 计算编辑与预览并列、项目列表与详情分栏、报价并列 PDF；辅助字号回到单列；字段读出名称和单位；大字号材料名称可换行；深色模式与键盘导航单独验证。 |

## 已通过的验证

- `Build/UIFix-20260908/Validation.xcresult`：86 项业务测试、11 项 iPhone 16 Pro UI 测试，全部通过。
- 新业务用例覆盖非法数量及字段定位、跨筛选累加选择、报价新增/修改/删除比较；既有计算、价格转换、备份、PDF/CSV 回归均通过。
- 手机 UI 覆盖中英文、跨币种确认、模板创建、收藏复用、搜索恢复、材料页切换、数量与键盘导航、选择性批量修改与撤销、报价版本及导出失败后重试。
- 最大辅助字号 + 深色模式：输入可用，辅助功能字段描述和特征自动审计通过。该自动审计不等同于真人逐句 VoiceOver 朗读体验，也未覆盖所有页面的对比度审计。
- 最终源码的 iOS Release 配置构建通过（`CODE_SIGNING_ALLOWED=NO`，编译验证，不是签名归档或上传）；日志 `Build/UIFix-20260908/release-verified.log`。
- `git diff --check` 与中英文 `.strings` 语法检查通过。

回归发现并修复了最大字号底栏过高、材料名称截断、清除搜索后键盘未退出、模板预览定位，以及 iPad 纵屏项目侧栏隐藏、同一表单行按钮事件联动问题。模拟器启动/迁移阻塞及空筛选的 0 用例结果不计入通过数量。

### 小屏与 iPad 补充验收

- iPhone SE（iOS 18.2）：86 项业务测试全部通过；13 个不同 UI 用例在整套运行及针对性复测后均取得通过结果。
- `SmallPhoneFinal.xcresult`：99 项中通过 97 项（86 业务 + 11 UI）。两处 UI 失败是测试滚动跨过目标输入、系统分享控件查询不适配手机。没有把这份结果包记为整套通过。
- `SEFinalRetest.xcresult`：最大辅助字号与深色模式、收藏复用、保存撤销与查看项目 3 项通过。分享取消后的状态标签位于屏幕下方，补上滚动定位后继续复测。
- `SEShareVerified.xcresult`：PDF 系统分享用例通过，包含打开分享面板、取消、显示已保存状态，以及返回报价历史确认 v1 存在。
- iPad Pro 11 英寸 M4（iOS 18.2）：横屏计算/PDF 分栏、保存反馈/撤销/查看项目、系统分享 3 个不同用例均通过。结果来自 `iPad3.xcresult` 的 2 项通过，以及修正系统分享控件查询后的 `iPadShare.xcresult` 的 1 项通过。
- 已查看小屏横屏、最大辅助字号深色模式、iPad 两列计算与真实 PDF、系统分享截图。真人 VoiceOver 逐项朗读和全页面对比度检查未执行。

最终代码复核覆盖保存/撤销、币种处理范围、批量选择、报价版本保存顺序及分栏导航，未发现阻断本轮交付的问题。没有数据库结构变更。后续计价折叠调整和构建 10 的提交、上传记录见 [发布记录](AppStore/Release-1.1.0-10-2026-09-08.md)。

## 计价折叠后续调整

移除顶部“展开完整报价设置”开关。计价在原表单位置作为默认折叠分组，点击展开，收起时显示金额摘要；每次进入计算页重新默认收起。单价、费用、来源和备注内容不会因收起而清空，错误定位仍可自动展开计价。

iPhone SE 验收通过：展开、修改单价、收起、重新展开保留数值、重新进入默认折叠。截图：[折叠状态](UI-Verification-2026-09-08/pricing-collapsed.png)。
