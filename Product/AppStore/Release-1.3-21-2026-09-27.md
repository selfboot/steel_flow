# SteelFlow 1.3 (21)

本次版本新增繁体中文、日语、韩语；加上原有英文、简体中文，共支持五种语言。

## 实现范围

- 每种语言覆盖全部 568 个本地化键，包括计算器、材料、项目、计价、设置、购买、备份、反馈与错误提示。
- 设置内可手动选择语言；跟随系统时采用系统偏好列表中首个支持的语言，并保留地区设置。
- 区分 `zh-Hans` / `zh-Hant`，正确识别台湾、香港、澳门及带显式书写系统的区域代码。
- 项目报价语言可独立选择。两种新建项目入口都默认使用当前 App 语言；已有项目保留原来的报价语言。
- PDF 标题、字段、内建材料名称、日期和格式化文本使用项目报价语言。用户输入的客户、公司、材料、说明与条款原样保留。
- 备份校验接受五种语言，导入后保留 App 与报价语言；旧备份格式继续支持。
- 导航标题按当前语言重新解析，修复应用内切换语言后的旧标题。
- 计算草稿独立记录输入数字的地区格式；切换语言时先转换数值，再更新格式与自动保存，避免密度、重量或价格被小数点与千位分隔符误读。新计算的默认输入也按当前地区转换。
- `project.yml` 与生成的 Xcode 项目均为版本 `1.3`、构建 `21`。

## 上架文案

`Metadata/metadata.json` 已更新五种语言的 1.3 更新说明，并加入繁体中文、日语、韩语的名称、副标题、关键词、宣传文本与 Pro 商品文案。新增完整描述位于 `Metadata/zh-Hant.md`、`Metadata/ja.md`、`Metadata/ko.md`。名称、副标题、关键词及宣传文本已校验字符长度。

Pro PDF 不再显示顶部默认 SteelFlow 名称或页脚生成署名，文件名也使用中性的 Quote 前缀；用户填写的公司名称、联系方式与 Logo 保留。五种语言的商店描述与 App 内 Pro 权益文案均明确支持去除 SteelFlow 标识。免费版保留品牌标识。

这些是本地待上架资料。本次没有上传构建、修改 App Store Connect 版本或提交审核。

- 价格编辑页、项目税率与加价率读取统一使用不舍入、不添加千位分隔符的地区输入转换；存储仍使用规范小数格式。
- 计算器历史价格选择原本在界面层已有转换，本次将转换收拢到 `CalculatorDraft.apply(priceEntry:locale:)`，调用者必须提供输入地区。
- 重置计算按当前地区生成默认尺寸，公制与英制所有型材默认值均可正确计算。
- `RegionalInputFixes.xcresult`：100 项单元测试、3 项 UI 测试通过。覆盖高精度价格往返、税率反复编辑保存、语言切换与草稿重启保留，以及重置后仍为 47.1 kg。

## 历史价格重置与撤销验证

- 重置计算同时清空历史价格选择和“价格已保存”状态，再次选择同一条价格可正常应用。
- 撤销重置会恢复原草稿、历史价格选择与保存提示；历史价格只在用户选择时加载，恢复选择状态不会覆盖用户手动调整的单价。
- `PriceResetFix.xcresult`：100 项单元测试、2 项 UI 测试全部通过。德国地区格式下，重置并重选后单价恢复为 2.345；将其手动调整为 4.567 后再重置、撤销，仍保留 4.567 及原历史价格选择。默认重量重置测试继续通过。
