# 报价 PDF 视觉优化

用户要求使用 image gen 改善整体清晰度，并去掉右下角疑似阴影效果。旧版没有投影，实际为总额填色背景，墨绿款还包含通栏深色总额区。按白底、清晰文字和细分隔线方向实现。

使用内置 image_gen 工具，输入旧版蓝色、墨绿 PDF 首页作为信息结构参考。生成设计板：`imagegen-reference.png`。此图仅作设计参考，App 导出继续使用 UIKit 矢量文字，不嵌入生成图片。

## 设计落地

- 蓝色、墨绿、黑白款：左侧公司信息，右侧报价标题与编号，细线分区。
- 客户与日期分栏；日期增加明确标签，八种语言本地化。
- 浅色表头配深色文字，明细全部白底，用细线和留白分行。
- 品名加粗、规格弱化但保持打印对比度；数量与金额使用等宽数字并右对齐。
- 右侧小计、税额、总价均白底，无投影、无色块；总价增加字号及分隔线。
- 大金额分配更多宽度；可容纳时保持汇总三行在同一页。
- 经典款保持原有版式；付费去品牌、内容和默认样式逻辑保持原规则。

最终提示词见 `imagegen-prompt.txt`。使用内置工具，无 CLI/API 回退。

## 移除条款和左下角文案

构建和 57 项单元测试通过，见 `NoFooterFinal.xcresult`；覆盖四样式 × 八语言 × 免费/Pro 的条款与页脚移除，并验证页脚仅有页码、隐藏长条款不增加页数。长文本换行测试改用公司地址和长明细继续验证。三份 v2 PDF 已更新并视觉检查。
