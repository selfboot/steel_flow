# 新增商务报价样式

在经典、清爽蓝、商务墨绿、极简黑白之外新增三种真实排版，共七种。内置 image gen 用于生成参考板，App 继续通过 UIKit 绘制可选择文字的 PDF。

| 样式 | 版式与重点 |
| --- | --- |
| 正式商务 / Executive | 居中公司抬头与报价标题，双细线，正式信笺感；表头仅用上下边线。 |
| 现代重点 / Modern Focus | 左侧大标题与细竖线，右侧公司信息；通栏汇总与大字号总价。 |
| 清晰账式 / Business Ledger | 紧凑标题行，明细表格带完整列线，紧凑行距；跨页重复表头。汇总独立留白，小计与税额疏朗排列，总价前仅保留一条细线。 |

所有样式保持白底总额，无投影、无条款、无左下角文案。仅保留页码，已有 Pro 去品牌规则继续生效。旧样式 raw value 不变，新样式自动参与项目、模板、备份、快照与设置默认样式。

名称及说明覆盖英文、简体、繁体、日语、韩语、德语、西班牙语和法语。选择器展示实际渲染器生成的缩略图。

`imagegen-reference.png` 为内置工具生成的参考图，`imagegen-prompt.txt` 为完整提示词。参考图的字体与装饰仅作方向，实际 PDF 以导出示例为准。

本轮修改已随 1.3（24）上传苹果。

## 账式汇总留白调整
